**Vedapath Ramayan – Valmiki Ramayan Reader & Translator**

A devotional and educational web app to read, explore, and understand the Valmiki Ramayan with ease.

**📖 What It Is**

Vedapath Ramayan is a web-based reader & translator for the ancient epic Valmiki Ramayan.
Built with passion by Jitendra Kumar Maurya, this project aims to offer:

Clean, readable presentation of the Ramayan

Easy navigation by chapters / categories

Bilingual support (original text + translation)

Feedback / contact features

Mobile-friendly design

Check out the live demo: jite2005.github.io/vedapath-ramayan
 
jite2005.github.io

**🧰 Tech Stack**

HTML5 / CSS3 / JavaScript

Responsive / mobile-friendly layout

Easy integration of text / translation content

Potential for adding more features: search, bookmarking, audio, etc.
